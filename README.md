## 📖 Description
**FitLog** is a dynamic, responsive, and performance-optimized workout planning web application. Designed with a sleek dark-neon theme (`#C2F800`), it empowers users to explore fitness exercises, seamlessly organize their daily workout routines ("Today's Plan"), and bookmark specific routines for future sessions ("Saved"). 

## ⚡ Key Features

| Feature | Description |
| :--- | :--- |
| 🗂️ **Dynamic Workout Management** | Instantly add exercises to your daily plan or save them for later with real-time UI updates. |
| 🔄 **Smart Sorting Logic** | Organize active workout lists by Duration, Calories Burned, or Alphabetically (A-Z). |
| 📱 **Responsive Navigation** | Mobile-friendly hamburger menu with dynamic active-route highlighting (`usePathname`). |
| 🖼️ **Optimized Media** | Utilizes Next.js `<Image>` components with precise `sizes` attributes for warning-free performance. |
| 🛡️ **Duplicate Prevention** | Built-in validation checks (via JS/TS array methods) to alert users if a workout is already saved. |
| 🏗️ **Component Architecture** | Clean separation of Server and Client components for improved SEO and initial page load speeds. |
